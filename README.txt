WINTER ARC V1
================
Fichiers :
- index.html
- style.css
- app.js
- manifest.json
- icon.svg

La V1 fonctionne dans un navigateur et sauvegarde les données dans le stockage local de l'appareil.
Pour l'utiliser comme une app iPhone, elle doit être hébergée sur une adresse HTTPS, puis ajoutée à l'écran d'accueil depuis Safari.

Limitation V1 :
- Les pas et le sommeil sont saisis manuellement.
- La connexion automatique à Apple Santé / une montre nécessite une version iOS native ou une intégration spécifique.
